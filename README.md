# Чисельне моделювання та ідентифікація параметрів поперечних коливань пружної струни на основі методу головних компонентів (PCA) та регресійних моделей машинного навчання

Репозиторій програмного комплексу магістерської кваліфікаційної роботи **«Ідентифікація параметрів коливань закріпленої струни на основі методу головних компонентів (PCA) та регресійних моделей машинного навчання»**.

Увесь код строго структуровано відповідно до розділів та підрозділів дипломної роботи (**Розділ 2**, **Розділ 3**, **Розділ 4**). Програмний комплекс повністю відтворює **усі 20 наукових рисунків (Рисунки 2.1–2.9, 3.1–3.2, 4.1–4.9)** та **усі 16 розрахункових і експериментальних таблиць (Таблиці 2.1–2.8, 4.1–4.8)**, а також формує повний синтетичний датасет і книгу Microsoft Excel.

## Швидкий старт

### Робота у Google Colab
1. Відкрийте `Diploma_Full_Pipeline.ipynb` або будь-який із розділових ноутбуків у папці `notebooks/` безпосередньо в Google Colab.
2. Усі таблиці та графіки вже вбудовані у комірки ноутбуків для миттєвого перегляду.
3. Для повторного виконання всіх розрахунків натисніть **`Середовище виконання` -> `Виконати все` (`Runtime` -> `Run all`)**.
